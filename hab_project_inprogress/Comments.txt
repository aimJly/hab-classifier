The starter code contains the entire hugging face dataset. Most of this git repo is making sure the data can be accessed locally on a laptop. 

The folder in hab-classifier\hab_project_inprogress\tmp_hf_dataset\data shows all places where HAB satellite image data was collected in different regions. 
Each file contains metadata, for the location, weather, and high/medium/low counts which should be the severity level of HABs.

Currently there is some issues with training the model because of 
1) importing library errors 
2) entire dataset takes long time to download 
3) issues with creating the labels on each image (ex: B0_4.tif, B0_8.tif, etc..) to only just focus on severity level (high, medium, low)

If you try running this project in train.py, only runs properly using a command. Not a good idea to run/redownload the entire hugging face dataset.

The exact command to run train.py might be different on your coding environment. I used visual studio.
